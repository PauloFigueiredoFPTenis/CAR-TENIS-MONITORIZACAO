# Privacy Policy — CAR Tennis Monitoring

**Last updated: 17 November 2026**

## 1. About this project

CAR Tennis Monitoring is an experimental, independently developed application intended to explore the use of WHOOP data for monitoring physiological recovery, sleep and training load in tennis.

The application is currently being tested exclusively with the developer's own WHOOP account.

It is not currently an official application of the Portuguese Tennis Federation.

## 2. Data collected

With the user's authorization, the application may access the following information through the WHOOP API:

- Heart rate variability (HRV)
- Resting heart rate
- Recovery scores
- Sleep duration and sleep metrics
- Physiological strain and activity information

## 3. Purpose

Data will be used solely to test data collection, develop monitoring tools and explore methods of analysing physiological responses to training.

## 4. Data storage and security

During the initial testing phase, data will be stored locally on the developer's computer, with access restricted to the developer. Access credentials will not be published in the public GitHub repository.

## 5. Data sharing

Personal data will not be sold or used for advertising. No athlete data will be collected during this initial testing phase.

## 6. User rights

The user may revoke the application's access to WHOOP data. Requests concerning access, correction or deletion of personal data may be directed to the developer.
